```bash

```

### 数据格式

#### CSV 格式（收集器输出）

```csv
symbol,date,open,high,low,close,volume,factor,open_qfq,high_qfq,low_qfq,close_qfq,open_hfq,high_hfq,low_hfq,close_hfq
SZ000001,2020-01-02,10.5,10.8,10.3,10.6,12345678,1.0,10.5,10.8,10.3,10.6,10.5,10.8,10.3,10.6
SZ000001,2020-01-03,10.6,10.9,10.4,10.7,12345679,1.0,10.6,10.9,10.4,10.7,10.6,10.9,10.4,10.7
```

**字段说明**：
- `symbol`: 股票代码（qlib格式：SZ000001, SH600000）
- `date`: 交易日期
- **基础字段（原始价格，未复权）**：
  - `open`, `high`, `low`, `close`: 开盘价、最高价、最低价、收盘价（原始价格，未复权）
  - `volume`: 成交量
  - `factor`: 累积复权因子（Tushare 的 `adj_factor`，用于计算复权价格）
- **前复权价格字段**（方便查阅）：
  - `open_qfq`, `high_qfq`, `low_qfq`, `close_qfq`: 前复权价格（保持最新价格不变，调整历史价格）
- **后复权价格字段**（方便查阅）：
  - `open_hfq`, `high_hfq`, `low_hfq`, `close_hfq`: 后复权价格（保持历史价格不变，调整最新价格）

**复权计算说明**：
- 后复权价格 = 原始价格 × `factor`
- 前复权价格 = 原始价格 × (`factor` / `factor_latest`)
- 其中 `factor_latest` 是最近一个交易日的 `factor`

#### Qlib 格式（转换后）

```
~/.qlib/qlib_data/cn_data/
├── calendars/
│   └── day.txt          # 交易日历

    └── ...
```

### 数据存储机制

#### 字段级别存储

Qlib 使用**字段级别的独立存储**，每个指标存储为独立的二进制文件：

```
~/.qlib/qlib_data/cn_data/features/sz000001/
├── open.day.bin          # 开盘价（独立文件）
├── close.day.bin         # 收盘价（独立文件）
├── volume.day.bin        # 成交量（独立文件）
├── pe.day.bin            # 市盈率（新增，独立文件）
└── turnover_rate.day.bin # 换手率（新增，独立文件）
```

**关键优势**：
- ✅ 每个字段独立存储，互不影响
- ✅ 添加新字段时，只需要转换新字段
- ✅ 更新数据时，只需要追加新日期，不修改已有数据

#### bin 文件结构

```
[起始日期索引(4字节)] [数据1(4字节)] [数据2(4字节)] ... [数据N(4字节)]
```

- **前4字节**：起始日期在交易日历中的索引
- **后续字节**：按日期顺序排列的数据值（float32格式）

#### 增量更新机制

**核心原理**：使用追加（append）模式，新数据追加到文件末尾

```python
# dump_update 模式的关键代码
if bin_path.exists() and self._mode == self.UPDATE_MODE:
    # 追加模式：新数据追加到文件末尾
    with bin_path.open("ab") as fp:  # "ab" = append binary
        np.array(new_data).astype("<f").tofile(fp)
```

**工作流程**：
1. 读取现有交易日历和股票列表
2. 识别新数据（日期大于现有结束日期）
3. 追加新数据到 bin 文件末尾
4. 更新交易日历和股票列表的日期范围

**重要结论**：**不需要修改原有的 bin 文件，只需要追加新数据即可！**

#### 测试数据访问

```python
from qlib.data import D

# 获取交易日历
calendar = D.calendar(start_time='2024-01-01', end_time='2024-12-31', freq='day')
print(f"交易日数量: {len(calendar)}")

# 获取股票列表
instruments = D.instruments(market='all')
stock_list = D.list_instruments(instruments=instruments, as_list=True)
print(f"股票数量: {len(stock_list)}")

# 获取单只股票数据
data = D.features(['SZ000001'], ['$open', '$close', '$high', '$low', '$volume', '$close_hfq', '$close_qfq'],start_time='2024-01-01', end_time='2024-12-31', freq='day')

```

**注意**：在 Qlib 中访问字段时，使用 `$字段名` 格式（如 `$close`, `$volume`）

#### 复权价格的使用

**数据存储策略**：
- 基础字段（`open`, `high`, `low`, `close`）存储的是**原始价格（未复权）**
- `factor` 字段存储的是**累积复权因子**（Tushare 的 `adj_factor`）
- 额外提供了前复权（`_qfq`）和后复权（`_hfq`）价格字段，方便查阅

**在回测中使用复权价格**：

虽然 Qlib 的回测系统不支持直接选择复权方式，但可以通过以下方式处理：

**方式1：使用原始价格（默认）**
```python
# Qlib 默认使用原始价格（如果有 factor 字段）
data = D.features(
    ['SZ000001'],
    ['$close', '$factor'],
    start_time='2024-01-01',
    end_time='2024-12-31'
)
# 原始价格 = $close
# 如果需要后复权：后复权价格 = $close * $factor
```

**方式2：在数据预处理时转换**
```python
# 如果需要使用后复权价格
data = D.features(
    ['SZ000001'],
    ['$close', '$factor'],
    start_time='2024-01-01',
    end_time='2024-12-31'
)
# 计算后复权价格
data['$close_hfq'] = data['$close'] * data['$factor']

# 如果需要使用前复权价格
factor_latest = data['$factor'].iloc[-1]  # 最新日期的 factor
data['$close_qfq'] = data['$close'] * (data['$factor'] / factor_latest)
```

**方式3：直接使用已存储的复权价格字段**
```python
# 如果转换时包含了复权价格字段
data = D.features(
    ['SZ000001'],
    ['$close', '$close_qfq', '$close_hfq'],  # 前复权和后复权价格
    start_time='2024-01-01',
    end_time='2024-12-31'
)
# 直接使用 $close_qfq（前复权）或 $close_hfq（后复权）
```

**转换时包含复权价格字段**：
```bash
# 转换时包含前复权和后复权价格字段
python dump_bin.py dump_all \
    --data_path ~/.qlib/tushare_data/cn_data \
    --qlib_dir ~/.qlib/qlib_data/cn_data \
    --include_fields open,close,high,low,volume,factor,close_qfq,close_hfq \
    --file_suffix .csv
```

**复权方式说明**：
- **前复权（Forward Adjustment）**：保持最新价格不变，调整历史价格。适合分析历史走势。
- **后复权（Backward Adjustment）**：保持历史价格不变，调整最新价格。适合分析历史成本。
- **原始价格**：未复权的实际交易价格。适合需要精确交易价格的分析。

### 增量更新数据

#### 更新更多日期的数据

**核心机制**：使用 `dump_update` 模式，新数据追加到 bin 文件末尾，**不修改已有数据**。

```bash
# 1. 更新CSV数据（只收集新日期）
python collector.py collect \
    --save_dir ~/.qlib/tushare_data/cn_data \
    --token YOUR_TOKEN \
    --start 2025-01-01 \
    --end 2025-01-31 \
    --interval 1d

# 2. 增量转换为Qlib格式（追加模式）
cd ../../..
python scripts/dump_bin.py dump_update \
    --data_path ~/.qlib/tushare_data/cn_data \
    --qlib_dir ~/.qlib/qlib_data/cn_data \
    --include_fields open,close,high,low,volume,factor,close_qfq,close_hfq \
    --file_suffix .csv
```

**工作流程**：
1. Collector 检查现有CSV，只下载缺失日期的数据
2. `dump_update` 读取现有交易日历和股票列表
3. 识别新数据（日期大于现有结束日期）
4. 追加新数据到 bin 文件末尾（使用 "ab" 模式）
5. 更新交易日历和股票列表的日期范围

**安全性**：
- ✅ 追加模式不会修改已有数据
- ✅ 即使更新失败，原有数据不受影响

## 数据维护

### 常见问题

#### Q1: 数据收集很慢怎么办？

**解决方案**：
1. 增加 `max_workers`（但要注意 API 频率限制）
2. 使用缓存机制（默认已开启）
3. 分批收集，使用 `--limit_nums` 限制数量

#### Q2: API 调用失败

**原因**：
- Token 无效
- 积分不足
- 频率限制

**解决**：
1. 检查 Token 是否正确
2. 登录 Tushare 检查积分
3. 增加 `delay` 参数

#### Q3: 数据为空

**原因**：
- 股票已退市
- 时间范围内无交易
- API 权限不足

**解决**：
1. 检查股票代码格式
2. 确认时间范围
3. 检查 API 权限

#### Q4: 转换失败

**原因**：
- CSV 格式不正确
- 字段缺失
- 日期格式错误

**解决**：
1. 检查 CSV 文件格式
2. 确认必需字段存在
3. 检查日期格式

#### Q5: 如何只收集特定股票？

**方式1：使用命令行参数**：

```bash
python collector.py collect \
    --save_dir ~/.qlib/tushare_data/cn_data \
    --token YOUR_TOKEN \
    --stock_list "000001.SZ,600000.SH,600519.SH"
```

**方式2：使用文件**：

创建 `stock_list.txt` 文件：
```
000001.SZ
600000.SH
600519.SH
```

然后运行：
```bash
python collector.py collect \
    --save_dir ~/.qlib/tushare_data/cn_data \
    --token YOUR_TOKEN \
    --stock_list_file stock_list.txt
```

**方式3：使用 Python 代码**：

```python
from collector import TushareCollector

# 创建股票列表
stock_list = ['000001.SZ', '600000.SH', '600519.SH']
collector = TushareCollector(
    save_dir='~/.qlib/tushare_data/cn_data',
    token='YOUR_TOKEN',
    stock_list=stock_list
)
collector.collect()
```

#### Q6: 如何清理缓存？

```bash
rm -rf ~/.qlib/tushare_data/cn_data/.cache
```

#### Q7: 转换时内存不足？

**解决方案**：
1. 减少 `max_workers`
2. 分批转换数据
3. 增加系统内存

#### Q8: 添加新字段需要重新下载所有数据吗？

**A**: 不需要！使用 `collect_extra_fields_only` 方法，只会下载新字段的数据，然后合并到现有CSV文件。

#### Q9: 如何知道哪些字段已经存在？

```bash
# 查看CSV文件的字段

# 查看Qlib格式的字段
ls ~/.qlib/qlib_data/cn_data/features/sz000001/
```

#### Q10: 可以添加自定义字段吗？

**A**: 可以！只需要：
1. 在CSV文件中添加新列
2. 使用 `dump_bin.py` 转换时包含该字段

```python
# 读取CSV
df = pd.read_csv('SZ000001.csv')
df['date'] = pd.to_datetime(df['date'])

# 计算自定义指标
df['custom_indicator'] = df['close'] / df['volume']

# 保存
df.to_csv('SZ000001.csv', index=False)

# 转换
python dump_bin.py dump_all \
    --include_fields custom_indicator \
    ...
```

#### Q11: 如果更新失败，原有数据会受影响吗？

**A**: 不会。因为使用的是追加模式，即使更新失败，原有数据仍然完整。只需要重新运行更新即可。

#### Q12: 可以回退更新吗？

**A**: 可以，但需要手动操作：
1. 备份 bin 文件（更新前）
2. 如果更新有问题，恢复备份
3. 或者使用 `dump_all` 重新转换整个数据集

### 性能优化

#### 1. 并发控制

## 参考信息

### 核心功能模块

#### 1. 数据收集器 (collector.py)

**主要功能**：
- 从 Tushare API 获取股票数据
- 支持多时间粒度（日线、分钟线）
- 智能复权处理：存储原始价格 + 复权因子，同时提供前复权/后复权价格字段
- 本地缓存机制
- 增量更新支持
- 指标扩展支持

**关键方法**：
- `collect()`: 收集所有股票数据
- `collect_extra_fields_only()`: 只收集额外字段（增量添加）
- `update_data()`: 更新数据到指定日期
- `_get_daily_data()`: 获取日线数据
- `_get_minute_data()`: 获取分钟线数据
- `_get_financial_indicators()`: 获取财务指标
- `_get_moneyflow_data()`: 获取资金流向数据

#### 2. 更新调度器 (update_scheduler.py)

**主要功能**：
- 自动更新数据到最新日期
- 集成 CSV 更新和 Qlib 格式转换
- 支持定时任务

**关键方法**：
- `update_to_bin()`: 更新数据并转换格式
- `daily_update()`: 每日更新（更新到昨天）

#### 3. 数据格式转换 (dump_bin.py)

**模式**：
- `dump_all`: 首次转换，创建新的 bin 文件
- `dump_update`: 增量更新，追加新数据到现有 bin 文件

### 支持的字段列表

- `low`: 最低价（原始价格，未复权）

**复权处理策略**：
- 存储原始价格 + 复权因子，提供最大灵活性
- 可以在回测时根据需要选择使用原始价格、前复权或后复权
