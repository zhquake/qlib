## 🎯 最终正确的公式

### 后复权
```python
后复权价格 = 原始价格 × adj_factor
```

**特点**：
- adj_factor是绝对系数（可以>100）
- 后复权价格会远大于原始价格
- 保持价格序列的连续性

**示例**：
```
2024-01-02: close=9.21, adj_factor=116.713
后复权价格 = 9.21 × 116.713 = 1074.93
```

### 前复权
```python
前复权价格 = 原始价格 × (当日adj_factor / 最新adj_factor)
```

**特点**：
- 保持最新价格不变
- 历史价格会变小（如果有分红）
- 最新日期：前复权价格 = 原始价格

**示例**：
```
2024-01-02: close=9.21, factor=116.713, latest=127.7841
前复权价格 = 9.21 × (116.713 / 127.7841) = 8.41

2024-12-31: close=11.70, factor=127.7841, latest=127.7841
前复权价格 = 11.70 × (127.7841 / 127.7841) = 11.70 ✅
```

## 📈 直观理解

### adj_factor的含义

adj_factor不是一个0-1的比例，而是一个**累积的绝对复权系数**：

- adj_factor = 116.713 意味着：从上市到2024-01-02，累积的分红配股使得后复权价格是原始价格的**116.713倍**
- adj_factor = 127.7841 意味着：到2024-12-31，这个倍数增长到了**127.7841倍**

### 为什么前复权价格会变小？

因为前复权保持**最新价格不变**：

```
最新日期(2024-12-31):
  原始价格: 11.70
  前复权价格: 11.70 (保持不变)

历史日期(2024-01-02):
  原始价格: 9.21
  如果不调整: 看起来涨了 (9.21 → 11.70)
  但期间有分红，实际涨幅更大
  
  前复权调整: 9.21 × (116.713/127.7841) = 8.41
  调整后涨幅: 8.41 → 11.70 (更准确地反映真实涨幅)
```

## 🔄 前复权 vs 后复权对比

| 项目 | 前复权 | 后复权 |
|------|--------|--------|
| 公式 | close × (current/latest) | close × factor |
| 最新价格 | = 原始价格 | ≠ 原始价格(很大) |
| 历史价格 | 变小 | 变大 |
| 用途 | 技术分析 | 长期走势分析 |
| 特点 | 保持当前价格 | 保持连续性 |
