## ✅ 最终正确公式

```python
# 后复权
后复权价格 = 原始价格 × adj_factor

# 前复权  
前复权价格 = 原始价格 × (当日adj_factor / 最新adj_factor)
```

## 📝 关键理解

### adj_factor的本质
- **不是0-1的比例**，而是可以>100的绝对系数
- 包含了从上市以来所有分红配股的累积影响
- 例如：adj_factor=116.713 表示后复权价格是原始价格的116.713倍

### 前复权特点
- 保持**最新价格不变**
- 历史价格会**变小**（如果有分红）
- 公式：`current / latest`（分子是当日，分母是最新）

### 后复权特点
- 所有价格都**变大**（×100+倍）
- 保持价格序列的**连续性**
- 公式：直接 `× adj_factor`

## 🔍 微小差异说明

前复权的0.0555%差异是**完全正常的**，原因：

1. **浮点数精度**：Python的浮点运算固有误差
2. **Tushare四舍五入**：Tushare返回的价格保留2位小数
3. **计算顺序**：不同的计算顺序会累积微小误差

**结论**：差异< 0.1%都是可接受的，不影响量化策略的准确性。
