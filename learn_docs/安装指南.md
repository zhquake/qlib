# Qlib 完整安装指南

本文档提供从零开始安装 Qlib 的完整步骤，包括 conda 环境创建、源码安装和依赖包安装。

---

## 快速开始（推荐）

### 方式一：使用自动化脚本（最简单）

```bash
# 1. 给脚本添加执行权限
chmod +x install_qlib.sh

# 2. 运行安装脚本
./install_qlib.sh
```

脚本会自动完成所有安装步骤。

---

## 手动安装步骤

如果脚本执行失败，或想了解详细步骤，可以按照以下步骤手动安装：

### 步骤 1: 安装 Conda（如果尚未安装）

#### macOS/Linux
```bash
# 下载并安装 Miniconda
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-x86_64.sh
bash Miniconda3-latest-MacOSX-x86_64.sh

# 或使用 Homebrew (macOS)
brew install miniconda
```

#### Windows
1. 访问 https://docs.conda.io/en/latest/miniconda.html
2. 下载 Windows 安装程序
3. 运行安装程序并按照提示完成安装

### 步骤 2: 创建 Conda 环境

```bash
# 创建名为 qlib 的 Python 3.10 环境
conda create -n qlib python=3.10 -y

# 激活环境
conda activate qlib
```

**注意**: 
- Python 版本支持：3.8, 3.9, 3.10, 3.11, 3.12
- 推荐使用 Python 3.10（稳定且兼容性好）

### 步骤 3: 安装基础依赖

```bash
# 确保 pip 是最新版本
pip install --upgrade pip

# 安装 numpy（Qlib 编译需要）
pip install numpy

# 安装 cython（Qlib 编译需要）
pip install --upgrade cython
```

### 步骤 4: 从源码安装 Qlib

```bash
# 进入 Qlib 源码目录
cd /Users/zhenzhang/workspace/qlib

# 以开发模式安装（推荐，便于修改代码）
pip install -e .

# 或普通安装模式
# pip install .
```

**安装模式说明**:
- `pip install -e .`: 开发模式（editable mode），修改代码后无需重新安装
- `pip install .`: 普通安装模式，代码修改后需要重新安装

### 步骤 5: 验证安装

```bash
# 验证 Qlib 是否安装成功
python -c "import qlib; print(qlib.__version__)"

# 验证 qrun 命令是否可用
qrun --help
```

### 步骤 6: 安装常用依赖包

#### 基础依赖（必需）

```bash
# LightGBM（用于基础示例）
pip install lightgbm
```

#### 深度学习依赖（可选，用于 LSTM、MLP 等模型）

```bash
# PyTorch
# macOS
pip install torch torchvision torchaudio

# Linux/Windows (CPU版本)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

# Linux/Windows (GPU版本，需要 CUDA)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
```

#### 可视化依赖（可选，用于结果分析）

```bash
pip install matplotlib seaborn plotly
```

#### 其他常用包

```bash
pip install scikit-learn jupyter ipykernel statsmodels
```

## 常见问题

### 问题 1: conda 命令未找到

**解决方案**:
1. 检查 conda 是否已安装
2. 初始化 conda（如果使用 Miniconda）:
   ```bash
   conda init bash  # Linux/macOS
   conda init powershell  # Windows PowerShell
   ```
3. 重新打开终端

### 问题 2: 编译错误（Mac M1/M2）

**解决方案**:
```bash
# 安装 OpenMP（LightGBM 需要）
brew install libomp

# 然后重新安装
pip install --force-reinstall lightgbm
```

### 问题 3: 安装过程中内存不足

**解决方案**:
- 关闭其他占用内存的程序
- 使用 `--no-cache-dir` 选项:
  ```bash
  pip install --no-cache-dir -e .
  ```

### 问题 4: 导入 qlib 时出错

**解决方案**:
1. 确保不在 qlib 源码目录中运行 Python
2. 检查环境是否正确激活: `conda activate qlib`
3. 重新安装: `pip install --force-reinstall -e .`

### 问题 5: qrun 命令未找到

**解决方案**:
```bash
# 检查是否安装成功
pip show pyqlib

# 检查 PATH 中是否有 qrun
which qrun

# 如果找不到，可能需要重新安装
pip install --force-reinstall -e .
```

## 验证安装完整性

运行以下命令验证所有组件是否正常：

```bash
# 1. 验证 Qlib
python -c "import qlib; print('Qlib version:', qlib.__version__)"

# 2. 验证 LightGBM
python -c "import lightgbm; print('LightGBM version:', lightgbm.__version__)"

# 3. 验证 PyTorch（如果安装了）
python -c "import torch; print('PyTorch version:', torch.__version__)"

# 4. 验证数据访问
python -c "import qlib; from qlib.constant import REG_CN; qlib.init(provider_uri='~/.qlib/qlib_data/cn_data', region=REG_CN); print('Qlib initialized successfully')"
```

## 卸载

如果需要卸载 Qlib：

```bash
# 激活环境
conda activate qlib

# 卸载 Qlib
pip uninstall pyqlib -y

# 或删除整个环境
conda deactivate
conda env remove -n qlib
```
