  - 理解标签的含义：预测未来收益

### 3.2 创建第一个数据集
- [ ] **使用代码方式创建数据集**
  ```python
  from qlib.data.dataset import DatasetH
  from qlib.contrib.data.handler import Alpha158
  
  # 创建数据处理器
  handler = Alpha158(
      start_time='2008-01-01',
      end_time='2020-08-01',
      fit_start_time='2008-01-01',
      fit_end_time='2014-12-31',
      instruments='csi300'
  )
  
  # 创建数据集
  dataset = DatasetH(
      handler=handler,
      segments={
          'train': ('2008-01-01', '2014-12-31'),
          'valid': ('2015-01-01', '2016-12-31'),
          'test': ('2017-01-01', '2020-08-01')
      }
  )
  
  # 查看训练集数据
  train_data = dataset.prepare('train')
  print(f"训练集形状: {train_data.shape}")
  print(train_data.head())
  print(f"特征数量: {len(train_data.columns) - 1}")  # 减去 label 列
  ```

## 阶段五：回测与评估（预计2-3天）

### 5.1 理解回测配置
- [ ] **学习回测参数**
  - `start_time`, `end_time`: 回测时间范围
  - `account`: 初始资金
  - `benchmark`: 基准指数
  - `exchange_kwargs`: 交易参数
    - `open_cost`, `close_cost`: 交易成本
    - `limit_threshold`: 涨跌停限制
    - `deal_price`: 成交价格（close/open）

### 5.2 运行回测
- [ ] **使用配置文件自动回测**
  - 在 `workflow_config_lightgbm_Alpha158.yaml` 中已包含回测配置
  - 运行 `qrun` 会自动执行回测

- [ ] **手动运行回测**
  ```python
  from qlib.backtest import backtest
  from qlib.contrib.strategy.signal_strategy import TopkDropoutStrategy
  
  # 创建策略
  strategy = TopkDropoutStrategy(
      signal=(model, dataset),
      topk=50,  # 选择 top 50 只股票
      n_drop=5   # 每次调仓时丢弃 5 只
  )
  
  # 回测配置
  backtest_config = {
      "start_time": "2017-01-01",
      "end_time": "2020-08-01",
      "account": 100000000,  # 1亿初始资金
      "benchmark": "SH000300",  # 沪深300指数
      "exchange_kwargs": {
          "freq": "day",
          "limit_threshold": 0.095,
          "deal_price": "close",
          "open_cost": 0.0005,
          "close_cost": 0.0015,
          "min_cost": 5,
      },
  }
  
  # 执行回测
  report_normal, positions_normal = backtest(
      executor=SimulatorExecutor(**backtest_config["exchange_kwargs"]),
      strategy=strategy,
      **backtest_config
  )
  ```

### 5.3 理解回测结果
- [ ] **分析回测指标**
  - `annualized_return`: 年化收益率
  - `information_ratio`: 信息比率（夏普比率的变种）
  - `max_drawdown`: 最大回撤
  - `excess_return`: 超额收益（相对基准）

- [ ] **查看详细报告**

### 6.1 理解模型保存机制
- [ ] **学习 Recorder 系统**
  - Qlib 使用 `Recorder` 管理实验
  - 模型自动保存到实验目录
  - 查看 `qlib/workflow/recorder.py` 了解保存机制

### 6.2 保存模型
- [ ] **使用 Recorder 保存**
  ```python
  from qlib.workflow import R
  
  with R.start(experiment_name="my_model"):
      model.fit(dataset)
      
      # 保存模型
      R.save_objects(**{"model.pkl": model})
      
      # 保存数据集配置（用于后续推理）
      dataset.config(dump_all=False, recursive=True)
      R.save_objects(**{"dataset": dataset})
  ```

- [ ] **手动保存模型**
  ```python
  # LightGBM 模型可以直接保存
  import pickle
  
  # 保存模型
  with open("my_model.pkl", "wb") as f:
      pickle.dump(model, f)
  
  # 加载模型
  with open("my_model.pkl", "rb") as f:
      loaded_model = pickle.load(f)
  ```

### 6.3 模型推理（预测）
- [ ] **使用保存的模型进行预测**

## 常见问题排查

### 问题1：数据下载失败
- 检查网络连接
- 尝试使用社区提供的数据源（见 README.md）

### 问题2：模型训练内存不足
- 减少股票池大小（如使用 csi100 而不是 csi300）
- 减少特征数量
- 使用更小的时间范围

### 问题3：回测结果异常
- 检查数据质量
- 检查交易成本设置
- 检查涨跌停限制设置

### 问题4：模型保存/加载失败
- 确保使用相同的 Qlib 版本
- 检查文件路径权限
- 确保数据集配置一致
