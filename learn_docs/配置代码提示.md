# Jupyter 代码提示配置指南

在 Jupyter 中启用代码自动补全、参数提示和类型提示有几种方案，推荐按优先级选择：

## 方案一：使用 JupyterLab + LSP（推荐）⭐

JupyterLab 提供更好的 IDE 体验，配合 LSP 扩展可以获得完整的代码提示。

### 安装步骤

```bash
# 1. 安装 JupyterLab
pip install jupyterlab

# 2. 安装 LSP 相关扩展
pip install jupyterlab-lsp 'python-lsp-server[all]'

# 3. 安装类型检查支持（可选，但推荐）
pip install pylsp-mypy

# 4. 启动 JupyterLab
jupyter lab
```

### 配置 LSP

创建或编辑 `~/.jupyter/jupyter_lab_config.py`：

```python
c.LanguageServerManager.language_servers = {
    "pylsp": {
        "argv": [
            "pylsp",
            "-v"
        ],
        "languages": ["python"],
        "version": 2,
    }
}
```

### 使用

- 启动后访问 `http://localhost:8888`
- 代码提示：输入时自动显示
- 参数提示：输入 `(` 后自动显示函数签名
- 类型提示：悬停变量/函数查看类型信息

## 方案二：使用 VS Code（最推荐）⭐⭐⭐

如果你使用 VS Code，这是最佳选择，提供完整的 IDE 体验。

### 安装步骤

1. **安装 VS Code 扩展**
   - 打开 VS Code
   - 安装 "Jupyter" 扩展（Microsoft 官方）
   - 安装 "Python" 扩展（Microsoft 官方）

2. **打开 Notebook**
   - 在 VS Code 中直接打开 `.ipynb` 文件
   - 或使用命令面板：`Cmd+Shift+P` → "Jupyter: Create New Jupyter Notebook"

### 功能

- ✅ 完整的代码自动补全
- ✅ 函数参数提示（输入 `(` 时显示）
- ✅ 类型提示（悬停查看）
- ✅ 错误检查
- ✅ 代码格式化
- ✅ Git 集成
- ✅ 调试支持

### 配置 Python 解释器

1. 按 `Cmd+Shift+P`
2. 选择 "Python: Select Interpreter"
3. 选择你的 Python 环境

## 方案三：Jupyter Notebook + 扩展

如果你坚持使用传统的 Jupyter Notebook，可以安装一些扩展。

### 安装步骤

```bash
# 1. 安装 nbextensions
pip install jupyter_contrib_nbextensions
jupyter contrib nbextension install --user

# 2. 启用 Hinterland（代码补全）
jupyter nbextension enable hinterland/hinterland

# 3. 安装 jupyter-lsp（需要 JupyterLab，但也可以尝试）
pip install jupyter-lsp
```

### 使用

- 启动 Jupyter Notebook
- 在代码 cell 中按 `Tab` 键触发自动补全
- 输入函数名后按 `Shift+Tab` 查看文档

## 方案四：使用 IPython 的自动补全

在 notebook 中直接使用 IPython 的功能。

### 快捷键

- `Tab` - 自动补全
- `Shift+Tab` - 显示函数签名和文档
- `Shift+Tab+Tab` - 显示完整文档
- `Shift+Tab+Tab+Tab` - 显示文档和源代码

### 示例

```python
# 输入以下代码，然后按 Shift+Tab 查看提示
from qlib.data import D
D.features(  # 在这里按 Shift+Tab 查看参数提示
```

## 故障排除

### 问题：代码提示不工作

1. **检查 Python 环境**
   ```python
   import sys
   print(sys.executable)
   ```

2. **重新安装扩展**
   ```bash
   pip install --upgrade jupyterlab jupyterlab-lsp
   jupyter labextension list
   ```

3. **清除缓存**
   ```bash
   jupyter lab --clear-cache
   ```

### 问题：类型提示不显示

1. 确保安装了类型检查工具
2. 检查代码是否有类型注解
3. 在 VS Code 中，确保 Python 扩展已启用

## 额外提示

### 在 Notebook 中查看函数签名

```python
# 方法 1：使用 ? 查看文档
D.features?

# 方法 2：使用 help()
help(D.features)

# 方法 3：使用 inspect
import inspect
print(inspect.signature(D.features))
```

### 启用更详细的错误提示

```python
%xmode Verbose  # 在 notebook 中运行
```
